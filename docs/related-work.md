| Работа | Что делает | Близость к нашему плану |
|---|---|---|

| DREAM, 2505.19201 | отдельный драфтер 0.24–0.56B, видит 75% визуальных токенов по вниманию цели; до 3.6×; есть SmolVLM | то же, отдельный драфтер |
| SpecVLM, 2509.11815; ViSpec, 2509.15235; HiViS, 2509.23928; Sparrow, 2602.15318; FOVEA, 2608.22883 | драфтеры EAGLE-типа со сжатым или выброшенным визуальным входом, проверка полная | то же |
| **GLANCE**, 2609.00355, 31.08.2026 **[сверено]** | блочный диффузионный драфтер за ОДИН проход, читает уже сплавленные состояния замороженной VLM; без потерь; до 3.05× | ближе всех по устройству; один проход, без многошагового обучения |

| GravityOCR, 2609.26638 | самоспекулятивный диффузионный драфтер с общими весами в OCR-VLM, один проход; меняет базовую модель | OCR, один проход |
| Обзор «Is Multimodal Speculative Decoding Ready for Diffusion-Based Parallel Drafting?», 2608.20743 **[сверено]** | DFlash / DSpark на Qwen3-VL; по отчёту: маскирование визуального K/V стоит лишь −4.2% приёмки, на высоком разрешении время ест префилл | прочитать целиком до позиционирования |

**Вывод.** Идея «драфтер читает сжатую картинку» сама по себе **не новая**.
Не найдено: драфтер внутри модели на её собственном KV-кэше (как Orthrus),
обученный на собственной цепочке уточнения, и контролируемый ответ на вопрос,
окупается ли многопроходный драфт на задачах с низкой энтропией (OCR,
документы). GLANCE и GravityOCR — однопроходные.

поведение доказуемо не меняется, скорость мерится офлайн на записанных
траекториях, без симулятора». Точный бейзлайн, который придётся бить, — PD-VLA.

## Модели и окружение, проверенные под T4

- **SmolVLM-256M-Instruct** — языковая часть SmolLM2-135M (наш первый стенд),
  SigLIP-512, 64 токена на плитку, с разбиением до ~1088 на картинку;
  Apache-2.0; в transformers нативно; веса bf16 → на T4 перевести в fp16.
  **SmolVLM-500M** — SmolLM2-360M.
- **InternVL3.5-1B** — языковая часть Qwen3-0.6B (наш второй стенд); Apache-2.0.
- **VLA-0-Smol** **[сверено]** — SmolVLM2-500M, действия текстом (бины),
  блок на 8 шагов, LIBERO 94.1%, «медленная из-за авторегрессии»; Apache-2.0;
  запуск через `lerobot-eval`.
- **MiniVLA** — Qwen2.5-0.5B, 7 токенов на шаг или VQ-блоки; MIT; веса в
  формате Prismatic.
- **SmolVLA** — 450M, flow matching, 10 шагов, блок 50.
- **LIBERO** на Kaggle T4 запускали (EGL, ~35 с на эпизод); стандарт — 400
  эпизодов. Офлайн-данные: `lerobot/libero`, 1693 эпизода, 1.9 ГБ.
- **The Cauldron** (VLM-инструкции): дешёвые OCR/документные подмножества —
  chartqa (0.8 ГБ), st_vqa (0.72 ГБ), infographic_vqa (0.29 ГБ). Лицензии у
  подмножеств свои, проверить перед публикацией.
