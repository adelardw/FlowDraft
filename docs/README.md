## Общие соглашения

### Метрики

| Имя в файлах | Смысл | Формула |
|---|---|---|
| `acceptance` (A) | принятых черновых токенов за цикл — качество драфтера | среднее по циклам |
| `tpf` | токенов на прямой проход, сквозное: префилл и последний цикл включены | `n_tokens / n_forwards` |
| `tpf_steady` | то же в установившемся режиме, без префилла | `произведено циклами / проходы циклов` ≈ `(A+1)/(n+1)` |
| `speedup` | ускорение по стенным часам против обычного AR-декода | `(ток/с наш) / (ток/с AR)` |
| `lossless` | вывод совпадает с жадным AR токен в токен | `True` в каждом жадном замере |

`n` — число проходов драфтера в цикле, `n+1` — вместе с проверкой. Обычный
AR-декод даёт `tpf = 1`.

**Какой TPF сравнивать с таблицей 1 Orthrus.** У них TPF = все токены / все
проходы, то есть наш `tpf`. Столбец «tokens per forward» в README — это
`tpf_steady`; он не зависит от длины генерации и годится для сравнения наших
конфигураций между собой, но не со статьёй напрямую.

### Усреднение

- **Таблицы README** — невзвешенное среднее по шести наборам (каждый набор с
  весом 1, независимо от числа промптов в нём).
- **Парные контрасты** — среднее разности по промптам, все промпты в один пул.
  Интервал — 95% ДИ: `1.96 · sd / √n`. Единица наблюдения — промпт: интервал
  отвечает на вопрос «устойчиво ли по задачам», а не «повторится ли на другом
  зерне обучения». Межзерновые интервалы есть только у SmolLM2-135M.

Пересчёт любого контраста: `python tools/paired.py <pp-A.jsonl> <pp-B.jsonl> [--metric tpf] [--cap 30]`.

### Протокол замера (если не оговорено иное)

- 460 промптов: gsm8k, math500, humaneval, mbpp по 100; aime24, aime25 по 30
  (это наборы целиком);
- жадный декод, блок `K = 32` (якорь плюс 31 черновая позиция), 64 новых
  токена, `float32`;
- каждый замер сверяется с жадным AR, `lossless = True` во всех жадных замерах.

### Расписания проходов

| Метка | `decode.jumps` | Проходов драфтера |
|---|---|---|
| n1 | `1` | 1 |
| n2 | `[[0,1],[0.5,1]]` | 2 |
| n3 | `[[0,1],[0.5,1],[0.75,1]]` | 3 |
| n4 | `[[0,1],[0.34,1],[0.67,1],[0.9,1]]` | 4, точка 0.34 вне обученной опоры |
| n4v | `[[0,1],[0.5,1],[0.7,1],[0.85,1]]` | 4, все точки внутри опоры |

### Инструменты

| Скрипт | Назначение |
|---|---|
| `tools/paired.py` | парные контрасты с 95% ДИ по построчным замерам |
| `tools/import_orthrus.py` | выпущенные веса Orthrus-Qwen3 → чекпоинт нашей обвязки, со сверкой ствола и анализом обученных проекций |
| `tools/orthrus_xcheck.py` | поцикловая сверка нашего декода с кодом авторов |
| `tools/orthrus_logits_check.py` | логиты одного прохода драфтера двумя реализациями на одном состоянии |
