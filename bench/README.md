# bench — стенд SmolLM2-135M

Скрипты, которыми получены числа из раздела README «SmolLM2-135M bench». Лежат
здесь, а не в `.work/`, потому что README на них ссылается как на команды
воспроизведения: несущему коду не место в каталоге с именем «черновик».

| файл | что делает |
|---|---|
| `final_ab.py` | пять рук по 2000 шагов, каждая своим составом лосса |
| `longer.py` | продолжение с чекпоинта до 6000 со снимками на 4000 |
| `measure.py` | приёмка и TPF, единица наблюдения — пара (промпт, сид) |
| `figures.py` | фигуры в `results/figures/` |

`measure.py` спаривает по обеим осям шума декода. Это не украшение: один и тот
же чекпоинт на одних промптах расходится до 0.16 токена между розыгрышами
приора, поэтому разность средних здесь ничего не значит.
