Код мультипликативного обусловливания (`model.adapter.conditioning_gate`) в
`src/models/base/fte.py` и `src/models/base/df_adapter.py` ОСТАВЛЕН: при выключенном
флаге он побитово инертен (проверено), а отрицательный результат должен быть
воспроизводим. Флаг по умолчанию `false`.

Члены согласованности траектории (`endpoint_weight`, `lambda`) остаются в
`src/configs/train.yaml` с нулевыми весами по умолчанию — они часть исходной
конструкции и используются пресетами из статьи, а не только этим стендом.
